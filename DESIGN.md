## Law
- Clean-room: NO SideFX code/headers/HDK. Public docs + `.geo`/`.bgeo` JSON schema only.
- IRON: never hardcode (param w/ default) · never /tmp · one live test at a time · each lane own worktree · trunk merges.
- Attribute model = Houdini's, exactly: Detail{points, vertices, prims} + attrib classes point/vertex/prim/detail + groups.
- Cook = lazy, cached, dirty-propagated; nodes never mutate upstream (COW `Arc` geometry).
- Tests: every SOP has an oracle test against a `.geo` cooked in Houdini (fixture in `tests/oracle/`, generated by `hython tools/oracle.py`).

## crates/geo contract (all lanes code against THIS)
```rust
pub type PointId = u32; pub type VertexId = u32; pub type PrimId = u32;
#[derive(Clone, Copy, PartialEq, Eq, Hash)] pub enum AttrClass { Point, Vertex, Prim, Detail }
#[derive(Clone)] pub enum AttrData { F32(Vec<f32>), I32(Vec<i32>), V2(Vec<[f32;2]>), V3(Vec<[f32;3]>), V4(Vec<[f32;4]>), Str{ idx: Vec<i32>, table: Vec<String> } }
#[derive(Clone)] pub struct Attribute { pub name: String, pub class: AttrClass, pub data: AttrData, pub type_info: TypeInfo /* point|vector|normal|color|quaternion|none */ }
#[derive(Clone)] pub enum PrimKind { Poly{ closed: bool }, Polyline, Sphere, Tube, Volume, PackedRef }   // v0: Poly/Polyline only
#[derive(Clone)] pub struct Prim { pub kind: PrimKind, pub verts: std::ops::Range<u32> }              // verts index into Detail.vertex_point
#[derive(Clone, Default)] pub struct Detail {
    pub point_count: u32,
    pub vertex_point: Vec<PointId>,          // vertex → point
    pub prims: Vec<Prim>,
    pub attrs: Vec<Attribute>,              // `P` V3 Point always present; `N`, `Cd`, `uv`, `id`, `name` by convention
    pub groups: Vec<Group>,                 // Group{ name, class: Point|Prim|Vertex, mask: Vec<bool> }
}
impl Detail { pub fn p(&self)->&[[f32;3]]; pub fn p_mut(&mut self)->&mut Vec<[f32;3]>; pub fn attr(&self,class,name)->Option<&Attribute>; pub fn attr_mut(..); pub fn add_attr(..); pub fn add_points(&mut self, n)->Range<PointId>; pub fn add_poly(&mut self, pts:&[PointId], closed)->PrimId; pub fn merge(&mut self, other:&Detail); pub fn bbox(&self)->([f32;3],[f32;3]); }
// IO
pub fn read_geo_json(bytes:&[u8]) -> Result<Detail, GeoError>;   // Houdini .geo (JSON) schema: fileversion, pointcount, vertexcount, primitivecount, topology.pointref.indices, attributes.{pointattributes,vertexattributes,primitiveattributes,globalattributes}, primitives [["Poly",...]] / PolygonCurve run, pointgroups/primitivegroups
pub fn write_geo_json(d:&Detail) -> Vec<u8>;                     // round-trip property: read(write(d)) == d · Houdini must load the output (oracle)
```

## crates/graph contract
```rust
pub struct NodeId(u32);
pub enum ParamValue { F(f32), I(i32), B(bool), V3([f32;3]), S(String), Menu(u32) }   // + channel expr later
pub struct ParamSpec { name, label, default: ParamValue, range: Option<(f32,f32)> }
pub trait Node: Send + Sync { fn type_name(&self)->&'static str; fn inputs(&self)->&[InputSpec]; fn params(&self)->&[ParamSpec]; fn cook(&self, ctx:&CookCtx, inputs:&[Arc<Detail>]) -> Result<Arc<Detail>, CookError>; }
pub struct CookCtx { pub time: f32, pub fps: f32, pub params: &ParamSet, pub log: &dyn Fn(&str) }
pub struct Graph { nodes, edges(from NodeId,out idx → to NodeId,in idx), display: Option<NodeId> }
impl Graph { fn add(node, params)->NodeId; fn connect(..); fn set_param(..) /* marks dirty + downstream */; fn cook(&mut self, id, time)->Result<Arc<Detail>> /* cached unless dirty or time-dependent */; fn to_json/from_json }
```
Registry: `sop::register(&mut Registry)` → `Registry::create(type_name)`.

# Endorphin 2.x file format — vocabulary survey

Clean-room, from data: this is the element/attribute vocabulary measured off the shipped sample files of one Endorphin 2.5.2 install (`Resources/`, 207 files walked). No vendor code, binary or documentation was consulted. Generated by `hexe-cli endo-survey`; reader = `crates/geo/src/endorphin.rs`.

## Container

- zlib stream (`78 01`) -> UTF-8 XML, one root element. Same container for every extension.
- Floats: attribute pairs `x="0.95"` (decimal, lossy) + `bx="3f735159"` (hex IEEE-754 single, exact). The reader prefers the hex twin (`(+hex)` below). Some attributes are hex-only (`bparam0`, `brestitution`, ...).
- `TransformMatrix` = `Vi Vj Vk` basis columns + `Vp` translation, each `x y z`. Joint matrices are parent-local; MetaBody matrices are joint-local.
- `.nmb` roots are `<cc>` with opaque text-encoded blobs in attributes (`vw`, `lo`, ...): NOT decoded (unknown); only `RefNames` and attribute names are read.
